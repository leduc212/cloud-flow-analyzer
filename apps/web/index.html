Find what makes a cloud flow slow, wasteful or fragile

Cloud Flow Analyzer checks a Power Automate flow against 30 rules drawn from Microsoft's guidance: loops that run one item at a time, data read per item, triggers that fire too often, missing error handling, secrets in run history. Each finding says why it matters and shows the better pattern. The browser extension does this inside the maker portal, next to the designer, and adds measurements from the flow's recent runs.

Try it on a flow

Paste a flow definition (from an export package, the Power Automate API, or Dataverse clientdata), open a .json file, or pick a sample. It's analysed here in your browser: nothing is uploaded.

Get the extension

Download the latest cloud-flow-analyzer-*.zip from the releases, unzip it, open edge://extensions (or chrome://extensions), turn on Developer mode and choose Load unpacked. Then open a flow in make.powerautomate.com, click the extension and Analyse this flow.
