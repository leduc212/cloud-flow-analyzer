Cloud Flow Analyzer is a browser extension that analyses Power Automate cloud flows. It has no server: it collects nothing, sends nothing to its authors or anyone else, and has no analytics or tracking.

What the extension reads

  • Your Power Automate sign-in. When the maker portal (make.powerautomate.com or make.powerapps.com) calls the Power Automate and Power Platform APIs, the extension reads the access token from those requests. It is kept in the browser's session storage (memory only, cleared when the browser closes), never written to disk, never logged, and only sent back to the same Microsoft APIs.
  • Flow definitions and run history, which it requests from the same Microsoft APIs with that token, only when you ask (Analyse this flow, Analyse recent runs, Analyse all). It only reads: it never creates, changes or deletes anything.

What it keeps in your browser

  • Findings you dismissed, per flow (browser local storage).
  • The daily request limit you picked, if any (browser local storage).
  • For runs it has read: run and action names, statuses, error codes and times, never the data inside the runs (IndexedDB, removed after 30 days or with Clear cached runs).
  • Results of Analyse all (grades and top findings) until the browser closes (session storage).

Removing the extension removes all of it.

The capture tool

The extension includes a capture tool for troubleshooting. It builds a file from API responses only when you click Download, anonymised by default, and it's up to you whether to share it.

This website

The analysis on this site runs in your browser; what you paste is not uploaded. The site is hosted on GitHub Pages, which may log visits as described in GitHub's privacy statement.
